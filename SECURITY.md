# Reporting a security issue

Contact **saxenism@bluethroatlabs.com** for suspected privacy or security problems.
Do not put sensitive reproduction material in a public issue. This document does
not establish a bug-bounty program or promise a response deadline.

Include the commit or build ID, browser and OS, expected behavior, actual behavior,
and concise reproduction steps. Use a synthetic image that demonstrates the issue.
If the issue concerns export, retain the exported file and its hash. If it concerns
network activity, describe when it happened and whether it came from BlueMask,
the hosting platform, a browser extension, or another process when known.

Relevant issues include private pixels remaining in an export, unintended network
or storage activity, bypassed cosmetic-blur consent, and incorrect claims about
offline operation. See the [privacy model](docs/PRIVACY.md) for the boundaries.

BlueMask is currently a release candidate. No supported stable-release series or
independent security certification has been announced.
