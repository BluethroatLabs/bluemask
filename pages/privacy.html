Privacy notice

25 September 2026 · Release candidate

BlueMask masks details you select in a photo or screenshot. It runs in your browser. This notice describes that processing. It does not mean the rest of an image is anonymous.

What stays on your device

Choosing a PNG, JPEG, or WebP reads it into browser memory for editing. BlueMask has no accounts, image uploads, analytics, telemetry, cookies, or saved sessions. Fonts and artwork are part of the page.

Download creates a new PNG named bluemask.png. It does not copy the original filename, camera details, or location metadata. The file you opened is left unchanged. Clear session drops the editor’s copy of the image. That is not a promise that the browser, the operating system, or a backup has erased it.

What a mask does not hide

Secure masking replaces the pixels you cover. Anything left uncovered stays visible, including nearby text, the shape of a box, and reflections. Cosmetic blur is an appearance effect and can leave recoverable detail. Review the download at full size before you share it.

The hosted page

Opening the website connects you to its host. The host can see ordinary connection data, such as an IP address and the time of the request. BlueMask does not add its own tracking. Links you follow, including GitHub and Bluethroat Labs, are separate sites with their own notices.

The offline edition is one HTML file. Using it while the device is disconnected shows that editing does not need a server. It does not prove that the browser, an extension, or the device is safe.

Messages you send us

We receive what you put in an email or a GitHub issue. Do not include private images or secrets. Security reports go to saxenism@bluethroatlabs.com. Other questions use the support page.
